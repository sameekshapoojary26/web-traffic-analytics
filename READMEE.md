# Web Traffic Analytics

## Project Description
This project analyzes website traffic to understand visitor behaviour and improve website performance.

## Objectives
- Calculate bounce rate.
- Calculate average session duration.
- Analyze pageviews by monthly cohort.
- Evaluate conversion by traffic source.
- Identify landing pages with low conversion.
- Generate traffic performance visualizations.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Project Files
- traffic_analysis.py
- Web Traffic Dataset

## Expected Outcome
Understand website traffic patterns and provide recommendations to improve user engagement and conversions.
